# Deep dive 2026-08-17: why we are not flagship-grade, with evidence

Three investigations run in parallel: primary-source research on Lovable's
2026 internals, a code-level audit of our rendering/serving pipeline, and
production log mining across VPS1/2/3. This document is the merged result and
the revised roadmap. Fixed-same-day items are marked ✅.

## Part 1 — What Lovable actually does (primary sources, cited in research)

The gap is not model quality. It is four specific engineering investments:

1. **SSR flip (May 2026).** Published sites moved from Vite SPA on Cloudflare
   Pages to TanStack Start SSR on Cloudflare Workers: per-route SSR/SSG/CSR,
   static routes pre-rendered at deploy, secrets as Worker bindings. Their
   own numbers: pre-rendering for crawlers alone lifted organic +2.9% and AI-
   tool referrals +98.5%. AI crawlers do not run JS; SPA-only publishing is
   invisible to the channel growing fastest. They inject curated TanStack
   rules into every prompt because the framework postdates model cutoffs.
2. **Provider load balancing with cache affinity.** >1B tokens/min across
   Anthropic/Vertex/Bedrock. Per-project fallback chains sampled as weighted
   permutations; health scored every 30s; PID controller targets 0.5% error
   rate. Cache affinity is a capacity strategy: rate limits charge on
   non-cached tokens.
3. **The vent tool.** A tool whose only job is letting the agent complain;
   a triage agent clusters vents and auto-opens PRs. ~20% actionable, ~10
   merged fixes/day. Their agents surface platform bugs; ours get punished
   by them (our validator incident survived weeks; a vent channel would have
   caught it day one).
4. **Preview at scale.** gVisor sandboxes on GKE (formerly 4,000+ fly.io
   instances), warm pools, 50-300 sandboxes/sec, per-component stable IDs
   from a custom Vite plugin for DOM↔source mapping, AST-in-browser visual
   edits, HMR not full reload.

## Part 2 — Confirmed technical bugs in our pipeline (ranked)

### Fixed same-day ✅
- **Unauthenticated recursive-delete with path traversal** on
  `/control/project/:projectId` (preview-service). Percent-decoded params
  made `..%2f` a real traversal out of PROJECTS_ROOT. Now requires valid id
  + `x-update-secret`; caller sends it. ✅
- **Third-party GA tag + Meta Pixel hardcoded in every generated site**
  (`social-template/index.html`): customer traffic reported into someone
  else's GA4/Facebook audience pool, pre-consent. Removed. ✅
- **Prior customer's branding as every new site's identity** (FGV titles,
  their OG images on Lovable's GCS, `author=Lovable`). Replaced with
  `{{APP_NAME}}` placeholders. ✅ (FGV PNGs in `src/assets` still referenced
  by 5 components — de-brand pass pending, see roadmap.)
- **Template placeholder substitution only ever replaced the first
  occurrence** (`ecg-template.ts` `.replace` → `.replaceAll`). ✅
- **Internal API surface published on every customer site**
  (`agent-template/public/api-docs.html` + `openapi.yaml`, Redoc from an
  unpinned CDN). Deleted. ✅
- **New-project creation failing in production** (44 failures/48h):
  `--prefer-offline` npm install vs stale cache metadata (ETARGET on
  `follow-redirects@1.16.0`). Cache primed live; code now retries online on
  ETARGET. ✅
- **Agent preview pushes timing out by design**: 15s client timeout vs ~90s
  server worst case; each retry re-materialized the project. Full-sync
  pushes now 120s. ✅

### SEO / SSR (the "SS/SSR" cluster) — open
- **HashRouter mandate defeats the entire SEO system.** The per-route
  `{route}/index.html` shells carry correct meta, but HashRouter boots,
  reads an empty hash, renders the homepage: meta/content mismatch on every
  route; one crawlable URL per site. Caddy's `try_files` fallback already
  supports BrowserRouter. Fix: BrowserRouter for published builds, keep
  HashRouter only inside the preview iframe.
- **Published sites are SPA-only.** Nearest-term flagship parity is
  Lovable's own interim step: pre-render routes to static HTML at publish
  (react-dom/server or a headless render against the built site), serve
  HTML-first to everyone; full SSR later if ever. Their data says the AI-
  crawler channel alone justifies it.
- **No sitemap/robots unless the user opens the SEO panel**, and the
  `Sitemap:` line is a relative URL (spec-invalid, ignored). Always emit at
  publish; absolute URL.
- **No 404s ever** (soft-404 on every unknown path). Add a 404 handler.
- **Redirects UI is a no-op**: full CRUD + table + RLS, zero consumers.
  Emit `redir` lines into the Caddy site config.
- **No Cache-Control on hashed assets**: every repeat visit revalidates
  everything. One Caddy header block = the cheapest big win in the audit.
- **Publish is destructive, not atomic**: `rm -rf` then file-by-file write;
  a mid-publish crash destroys the live site. Write to `.new`, rename.

### Performance — open
- **Preview: sync whole-project typecheck freezes all ~20 tenants** 12-18s
  per agent push (single process mode + synchronous `ts.createProgram`).
  Fork a worker + cache on content hash.
- **Full page reload on every edit** (`watch: null`, `sendFullReload`):
  scroll/form/app state destroyed per edit. Targeted HMR for CSS/self-
  accepting modules. Most-felt daily difference vs Lovable.
- **Every one-line edit pays ~5 whole-project traversals** (build check,
  snapshot cp, import check). Scope to changed files + importers.
- **Generated sites ship 508 kB gzip before first paint** (admin bundle,
  tiptap/recharts, eagerly imported on the public landing page). Lazy-load
  admin: measured 219 kB (-57%).
- **Web-client entry chunk 1.6 MB** (three.js + postprocessing eagerly
  imported by the landing Hyperspeed effect, loaded on every route incl.
  login). Lazy-load it.
- **Editor O(n²) during streaming**: 13 regexes over the full buffer per
  SSE token + full 3,800-line Editor re-render per chunk. Throttle to 50ms
  + move stream text to a ref.
- Smaller: Google Fonts via CSS `@import` (serialized round trips), 327 kB
  prior-customer PNGs as likely LCP, 0/13 imgs with dimensions (CLS),
  407 kB dead `public/tailwind.js`, unmemoized context values re-rendering
  Editor on the subscription heartbeat, dead `messages` state accumulating
  unboundedly, `PRE_INSTALLED_PACKAGES` prompt list steering the model
  toward react-icons/lodash/axios.

### Reliability (from log mining) — open
- **KB indexing FK violations** (~120/48h): guest/deleted projects without a
  `projects` row; retrieval context silently degraded. Skip indexing when
  the project row is absent.
- **Fork storm on boot-crashed previews**: no failure cache, no backoff,
  port released before child exit + `strictPort` → EADDRINUSE cascades that
  can exhaust the 30-port pool. Fast-fail 30s per project; release port in
  the exit handler.
- **Logger serializes error strings char-by-char** (`logger.error(msg,
  stringValue)` spreads the string). Made the ETARGET incident nearly
  unreadable.
- Anthropic provider still disabled on billing (user action pending).
