# SMEs Agent — Brand Identity Guide

*Prompt in. Everything runs.*

---

## 1. Brand foundation

**What it is:** A single app where small and medium enterprises manage their whole business — strategy, social, sales — by prompting into an AI agent that orchestrates every builder and tool behind the scenes.

**Positioning:** One prompt replaces a dozen disconnected tools.

**Audience:** Small and medium business owners and operators who want enterprise-grade capability without enterprise-level complexity or headcount.

**Personality:** Confident, direct, capable — a tool that *executes*, not just assists. Technical enough to feel credible, plain enough to feel usable by a non-technical business owner.

---

## 2. Logo

**Concept:** A terminal-style prompt mark — a chevron (`>`) and cursor bar — representing the core interaction: type what you need, the agent builds it.

**Primary files:**
- `logo/svg/smes-agent-icon.svg` — master vector, transparent background
- `logo/png/` — rasterized exports from 16px to 1024px, plus white-background and dark-background versions
- `logo/png/favicon.ico` — multi-resolution favicon (16/32/64/128/256px)

**Usage:**
- Icon-only identity — there is no wordmark lockup by default. Pair the icon with the product name set in plain text (not a styled logotype) in headers and navigation.
- Minimum clear space around the icon = the icon's own height, on all sides.
- Below 24px, don't shrink further — 16px is the floor (favicon size).
- Never recolor the chevron and cursor independently outside the approved palette. Never add a drop shadow, gradient, or outline glow.

See `logo/svg/smes-agent-icon-test-sheet.svg` and `logo/svg/smes-agent-logo-layouts.svg` for full versatility testing and layout variants (standalone, horizontal, stacked, clear space, scale test).

## 3. Color palette

| Role | Name | Hex | Use |
|---|---|---|---|
| Primary / dark base | Near-black charcoal | `#14161A` | Icon on light backgrounds, dark-mode surfaces, primary text |
| Accent | Signal green | `#34D399` | Cursor bar, one deliberate highlight only — never more than one accent element per use |
| Light background | Soft off-white | `#F6F8F6` | Default light-mode background |
| Dark background | Near-black charcoal | `#14161A` | Default dark-mode background |
| Secondary text | Muted gray-green | `#9CA3A0` | Captions, labels, disabled states |

**Rule:** exactly one accent element (the cursor bar) per logo instance. No gradients. No secondary accent colors. Flat fills only.

## 4. Taglines / slogans

Pick one primary tagline for consistent use; the others are for testing or contextual variation (ads, landing page headers, social bios).

1. **Prompt it. Built it. Run it.** *(primary recommendation — short, active, mirrors the product mechanic)*
2. One prompt, every system.
3. Your business, one prompt away.
4. Everything you run, from one line.
5. Type it. SMEs Agent builds it.
6. One app. Every builder. One prompt.
7. Run your business by prompting it.
8. Small business. Enterprise execution.

**Voice notes:** Active voice, verb-first, no exclamation points, no filler words ("simply," "easily," "seamlessly"). Say what it does, not how good it is.

---

## 5. Typography

- **Recommended typeface:** Inter Tight or General Sans (free, modern grotesk) — consistent rendering across devices, unlike system font stacks used in these draft files.
- **Weight:** Medium (500) for headings and the product name in navigation; Regular (400) for body copy.
- **Case:** Sentence case throughout — never Title Case or ALL CAPS in UI or marketing copy.
